## A section heading

Write in ordinary Markdown. Separate paragraphs with a blank line. You can use **bold**, *italics*, [links](https://example.com), quotations, and lists without touching the page code.

```ts
const piece = {
  title: "Something worth remembering",
  kind: "Note",
}
```

> A quotation can breathe a little differently from the rest of the piece.

When this is ready, change `draft: true` to `draft: false`. Rename the file to choose the URL: `my-piece.mdx` becomes `/writing/my-piece`.
